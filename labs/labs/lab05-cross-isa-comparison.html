Key Observation
RISC-V and ARM64 use 3-operand form (add dst, src1, src2) - non-destructive. x86-64 uses 2-operand form (add dst, src) - destructive, requiring an extra mov. MIPS uses 3-operand but has a branch delay slot (the addu executes before the jr takes effect).

CISC vs RISC Summary
RISC (RISC-V, ARM64, MIPS): Fixed encoding, simple instructions, load/store architecture, more instructions but simpler decode. CISC (x86-64): Variable encoding, complex instructions, memory operands, fewer instructions but complex decode. Modern x86 CPUs internally decode CISC instructions into RISC-like micro-ops.
