Lab 03: x86-64 Assembly Programming

Learn x86-64 assembly: 16 registers, two-operand instructions, memory addressing modes, and the System V AMD64 calling convention.

Objectives

  • Write and run x86-64 assembly programs
  • Use the 16 general-purpose registers (rax, rbx, rcx, ... r15)
  • Understand the System V AMD64 calling convention (rdi, rsi, rdx, rcx, r8, r9 for args)
  • Use x86-64 memory addressing: [base + index*scale + disp]
  • Understand variable-length instruction encoding (1-15 bytes)
  • Compare x86-64 (CISC) with RISC-V (RISC) for the same algorithms

Prerequisites

  • Complete Lab 01 and Lab 02 (RISC-V basics and stack frames)
  • Read Handbook Chapters 8-10 (x86-64 registers, instructions, calling convention)
  • Open the Simulator (supports x86-64 mode)

Hands-On Exercise 1: Hello x86-64 - Compile C, Read Assembly

Start by compiling a simple C function to x86-64 assembly and reading the output.

Open the simulator

Navigate to ../simulator/main.html and select x86-64 as the target architecture.

Enter this C code
int add(int a, int b) { return a + b; }
Compile and read the output

Click Compile. You should see something like:

add: mov eax, edi # eax = a (first arg in edi) add eax, esi # eax += b (second arg in esi) ret # return (result in eax)
Note the key differences from RISC-V
  • Arguments come in edi, esi (not a0, a1)
  • Return value in eax (not a0)
  • add is two-operand: the result overwrites the first operand
  • Register names use e prefix for 32-bit, r for 64-bit
Hands-On Exercise 2: Register Basics - mov, add, sub

Write x86-64 assembly using the two-operand instruction form. Learn how mov, add, and sub work.

Switch to assembly mode

In the simulator, select Assembly mode and x86-64 architecture.

Enter this program
.globl main main: mov rax, 10 # rax = 10 mov rbx, 20 # rbx = 20 add rax, rbx # rax = rax + rbx = 30 ret # return rax (30)
Run and verify

The exit code should be 30.

Try subtraction

Replace add with sub:

sub rbx, rax # rbx = rbx - rax = 10 mov rax, rbx # rax = rbx (for return)

Result should be 10 (20 - 10).

Compare with RISC-V

In RISC-V, the same operation is add a0, a0, a1 (3-operand, non-destructive). In x86-64, add rax, rbx modifies rax in place (2-operand, destructive). This means you often need extra mov instructions to preserve values.

Register Naming
  • rax, rbx, etc. = 64-bit (full register)
  • eax, ebx, etc. = 32-bit (lower half)
  • ax, bx, etc. = 16-bit (lower 16 bits)
  • ah/al, bh/bl = 8-bit
  • Writing to a 32-bit register zero-extends the upper 32 bits
Hands-On Exercise 3: Memory Addressing - [base + index*scale + disp]

x86-64 has a powerful memory addressing mode that combines base, index, scale, and displacement in a single instruction.

Understand the addressing formula

The general form is: [base + index * scale + displacement]

  • base: any general-purpose register (e.g., rbp)
  • index: any general-purpose register (e.g., rcx)
  • scale: 1, 2, 4, or 8
  • displacement: a constant offset
Enter this array access program
.globl main main: # Simulate: int arr[4] = {10, 20, 30, 40}; return arr[2]; # Allocate stack space for array sub rsp, 32 # 4 ints * 8 bytes = 32 bytes # Store values: arr[0]=10, arr[1]=20, arr[2]=30, arr[3]=40 mov DWORD PTR [rsp], 10 mov DWORD PTR [rsp+4], 20 mov DWORD PTR [rsp+8], 30 mov DWORD PTR [rsp+12], 40 # Access arr[2] using index addressing mov rcx, 2 # index = 2 mov eax, DWORD PTR [rsp + rcx*4] # arr[2] add rsp, 32 # Restore stack ret
Run and verify

The exit code should be 30 (arr[2] = 30).

Experiment with different indices

Change rcx to 0, 1, or 3 and verify you get 10, 20, or 40 respectively.

Compare with RISC-V

In RISC-V, the same array access requires two instructions:

# RISC-V equivalent of arr[2] slli t0, t0, 2 # t0 = index * 4 (shift left 2) add t0, t0, sp # t0 = base + offset lw a0, 0(t0) # load from memory

x86-64 does this in one instruction: mov eax, [rsp + rcx*4]. This is a key CISC advantage.

Hands-On Exercise 4: Loop - cmp, jl, jmp

Write a loop that sums 1 to 10 using x86-64 comparison and conditional jump instructions.

Understand x86-64 control flow

x86-64 uses cmp to set flags, then conditional jumps:

  • cmp a, b - computes a - b and sets flags
  • jl label - jump if less (signed)
  • jle label - jump if less or equal
  • jg label - jump if greater
  • je label - jump if equal
  • jmp label - unconditional jump
Enter the loop program
.globl main main: mov rcx, 1 # counter = 1 mov rax, 0 # sum = 0 loop: add rax, rcx # sum += counter inc rcx # counter++ cmp rcx, 10 # compare counter with 10 jle loop # if counter <= 10, loop ret
Run and verify

The exit code should be 55 (1+2+...+10).

Trace with the stepper

Use Step to watch rcx increment and rax accumulate. Notice how cmp + jle replaces RISC-V's ble.

Change to sum 1 to 100

Change cmp rcx, 10 to cmp rcx, 100. Result should be 5050.

Hands-On Exercise 5: Function Call - call/ret, rdi/rsi args

Write a function that takes two arguments and returns their sum, using the System V AMD64 calling convention.

Learn the calling convention
RegisterRole
rdi1st argument
rsi2nd argument
rdx3rd argument
rcx4th argument
r85th argument
r96th argument
raxReturn value
rspStack pointer
rbpFrame pointer (callee-saved)
Enter the program
.globl main main: mov rdi, 15 # 1st arg = 15 mov rsi, 27 # 2nd arg = 27 call add_two ret add_two: mov rax, rdi # rax = 1st arg add rax, rsi # rax += 2nd arg ret # return rax
Run and verify

The exit code should be 42 (15 + 27).

Add a stack frame (prologue/epilogue)

For functions that call other functions, add a proper frame:

add_two: push rbp # save old frame pointer mov rbp, rsp # set new frame pointer mov rax, rdi add rax, rsi pop rbp # restore frame pointer ret
push/pop vs sub/mov
push rbp is equivalent to sub rsp, 8; mov [rsp], rbp. It's a single instruction that both allocates stack space and stores a value. Similarly, pop rbp loads and deallocates in one step. This is a CISC convenience.

CISC vs RISC Tradeoff
x86-64 (CISC) can do more per instruction (e.g., add eax, [rsp+rcx*4] adds directly from memory), so it uses fewer instructions. RISC-V (RISC) uses more instructions but each is simpler and fixed-size. CISC = fewer instructions, more complex decoding. RISC = more instructions, simpler decoding.
